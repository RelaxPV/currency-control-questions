# Валютный контроль — вопросы для следующей версии

Страница с 12 вопросами для согласования документов, учебных тестов и обновлений Android-приложения. Адаптирована для телефона; интерфейс не требует внешних библиотек или шрифтов.

Денис может выбрать варианты и написать комментарии прямо на странице. Черновик автоматически сохраняется в localStorage этого браузера. Единственная кнопка «Отправить ответы» становится доступна, когда ответы есть на все 12 вопросов. При успешной отправке анкета сохраняется в закрытой базе для разработчика.

## Автоматическая отправка

`form-config.js` подключает открытый API-адрес `https://currency-control-answers-251026.blue-kid-0598.chatgpt.site`.

1. `GET /api/session` получает короткоживущий токен отправки. Запрос выполняется без cookies, с `credentials: omit` и `cache: no-store`.
2. `POST /api/responses` передаёт JSON-анкету как `text/plain;charset=UTF-8`; токен идёт в заголовке `X-Form-Token`.
3. Анкета содержит `requestId` и 12 ответов. Успех отображается только после ответа `{ ok: true, requestId }` с совпадающим идентификатором.

В публичных файлах нет ключей доступа к базе или секретов. `requestId` и данные последней отправки сохраняются вместе с черновиком, чтобы повторный запрос после неясного результата мог быть обработан сервером без дубля. Во время запроса поля временно блокируются. При ошибке черновик остаётся на устройстве.

Для просмотра откройте `index.html` или запустите `python -m http.server 8787 --bind 127.0.0.1`.

Публикация интерфейса: GitHub Pages, ветка `main`, каталог `/`. Сервис хранения ответов развёрнут отдельно; ему нужно разрешить CORS для опубликованного адреса страницы.

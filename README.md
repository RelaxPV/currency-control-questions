# Валютный контроль — вопросы для следующей версии

Пошаговая анкета из 12 вопросов для согласования следующей версии Android-приложения. На экране показан один вопрос. Интерфейс адаптирован для телефона и не требует внешних библиотек или шрифтов.

Денис выбирает варианты и пишет комментарии. «Далее» сначала сохраняет текущий ответ на сервере; переход происходит только после подтверждения. «Назад» сохраняет непустые изменённые ответы перед возвращением. Пустой черновик можно оставить при возвращении. На вопросе 12 кнопка «Отправить ответы» сначала сохраняет ответ, затем завершает анкету. Итоговый экран показывается только после подтверждения сервера.

## Автоматическая отправка

`form-config.js` использует API на том же домене с постоянным префиксом `/denis/`. Все запросы — POST JSON, `credentials: same-origin`, `cache: no-store`.

1. `api/session` с `{}` создаёт или восстанавливает сессию по HttpOnly cookie. Ответ содержит ранее сохранённые ответы, их редакции и номер продолжения.
2. `api/answers/N` принимает `{answer, requestId, expectedRevision?}`. Переход разрешён только после receipt с совпадающими `sessionId`, `number`, `answer` и положительной `revision`.
3. `api/complete` с `{}` завершает анкету. Только receipt с совпадающей сессией и `completed: true` открывает итоговый экран.

Серверная часть и SQLite находятся на том же VPS. Ключей доступа и секретов в клиентских файлах нет.

Локальный черновик (`denis-questionnaire-v2`) привязан к серверной `sessionId`; он помогает пережить потерю связи. Неподтверждённый `requestId` сохраняется для повторной попытки того же ответа. Во время запросов поля и навигация блокируются. При ошибке сохранения пользователь остаётся на текущем вопросе. При запуске без связи черновик показан только для чтения, без утверждения о серверном сохранении; доступна повторная попытка подключения.

При восстановлении несохранённой правки раннего вопроса анкета возвращается к ней; завершение запрещено, пока есть такие правки. Конфликт редакций (HTTP 409) показывает актуальный серверный ответ рядом с сохранённым локальным черновиком. Пользователь явно выбирает свой или серверный вариант перед продолжением.

Публикация: `https://webrelax.pro/denis/`. Для полноценного локального предпросмотра нужен тот же API под `/denis/api/`; статический сервер без API покажет экран ошибки подключения.
